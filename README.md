Forest Fire Decision Support System

An AI-assisted Forest Fire Decision Support System developed using NetLogo agent-based simulation, Python, Random Forest regression, and Streamlit.

Features

- Simulates forest-fire scenarios using NetLogo.
- Uses simulation-generated data to train a machine learning model.
- Predicts potential burned area based on selected forest conditions.
- Allows users to compare scenarios by changing input parameters.
- Provides a web interface for interactive predictions.

Technologies Used

- NetLogo
- Python
- Pandas
- Scikit-learn
- Streamlit

Run Locally

1. Install the required packages:

   `pip install -r requirements.txt`

2. Run the application:

   `python -m streamlit run app.py`

Disclaimer

Predictions are based on the simulation data and trained model. They are experimental estimates, not official wildfire forecasts.
